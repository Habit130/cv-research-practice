# 科研实践纪律

论文选读、复现、实验、报告或硬件结论时读取本文件。硬边界仍以根 `AGENTS.md` 为准;这里保留原协作规范中的细则。合并权威不在本文件:Agent 不合并,habit squash-merge。

## 目录职责

| 目录 | 职责 |
| --- | --- |
| `templates/` | 任务无关模板,复制到自己的任务目录使用 |
| `example/` | 作者的验证跑(ResNet-18 + CIFAR-10),参考体例;不得添加读者自己的任务内容 |
| `runs/` | 读者的实践闭环工作区,每个任务独立目录 |
| `docs/agents/` | 协作约定的补充说明 |
| `docs/adr/` | 已落定的重要决策及理由 |

遵守 [ADR-0001](../adr/0001-第二阶段形态-模板仓库而非第二份指南.md) 与 [ADR-0002](../adr/0002-仓库只含流程文本.md):仓库只收录流程文本与配套理论指南,不收录任务代码。上游实现优先克隆到仓库外,在记录中用 URL + commit hash 指认;若按 README 放在 `runs/<任务>/repro/<仓库名>/`,须先确认已被 Git 排除,不可作为嵌套仓库或 submodule 提交。

不得提交数据集、模型权重/checkpoint、缓存或敏感凭据。即使存放在被排除的上游目录里,也不得加入本仓库版本历史。提交前检查实际 diff,保留非本次任务产生的已有修改,只纳入当前任务相关文件。

## 科研工作纪律

- **先建记录,再跑实验**:任何训练、评测或冒烟测试启动前,先用 [实验记录模板](../../templates/experiment-log-template.md) 建好本次记录,再执行。运行后把真实结果写回同一份记录,不得事后补建不存在的运行记录。
- **结果必须真实可追溯**:只记录真实执行得到的指标,注明命令、代码版本、环境、设备和配置;未运行、失败或受限的步骤明确标注,不得编造指标或把预期当结果。报告中的每个数字须能追溯到实验记录。
- **条件化结论**:写清“指标在什么条件下从 X 变到 Y、代价是什么”,以及支持和不支持的判断;不写无条件的“效果变好”。
- **复现不许跳级**:按理论指南 §6.3 和 [复现清单](../../templates/repro-checklist.md),依次完成环境 → demo → checkpoint 评测 → 小规模训练 → 完整训练;记录当前级别的结果后再进入下一级。
- **方法论章节映射**:论文筛选与阅读 → Table 4、§4.3;环境排查 → Table 6;实验记录 → §6.4;baseline / ablation / fair comparison → §6.6、Table 7;报告叙事线 → §4.4–4.5。方法论问题引用对应章节,再结合当前任务落地,不另造流程或大段复述理论。不得编辑或删除根目录《计算机视觉科研入门指南.pdf》。

## 本地、云端与 GPU 服务器

各环境从 GitHub 获取同一任务分支与提交,共同遵守根 `AGENTS.md`;硬件相关结论以对应设备上的真实执行为依据。

| 环境 | 主要职责 | 验证边界 |
| --- | --- | --- |
| Mac 本地 Codex | 本地调试、Apple Silicon MPS 验证 | 记录实际 MPS 使用情况,CPU 回退须明示 |
| Codex Cloud | 文档维护、Issue 处理、代码审查、轻量 CPU 检查 | CPU 测试不构成 MPS/CUDA 硬件验证 |
| GPU 服务器 | 需要 CUDA 的训练与模型评估 | 记录实际 GPU、CUDA 与依赖版本及运行结果 |

仓库没有统一的 build / lint / test 命令。文档修改检查 Markdown 引用、路径、术语及规则一致性;任务代码的检查在对应上游实现与实际环境中完成。交付时写清已执行的检查、结果和未验证事项;不要为文档维护启动训练,不得把云端 CPU 测试冒充为 MPS/CUDA 验证。

## 跨环境交接

同一任务交接标明版本:在 Issue/PR 中写明分支、commit hash、已完成工作、实际检查环境与结果、未完成项及所需硬件。接手环境先获取该分支并核对提交,避免多个环境同时改写同一分支历史。

## 语言

笔记、记录、报告与协作说明使用中文;代码、命令、标识符及 baseline、ablation、checkpoint 等英文术语保留英文。Issue/PR 正文使用中文。固定标题、准则 ID、Code Review Rules 与 Conventional Commit subject 使用英文。
