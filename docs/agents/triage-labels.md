# Triage 标签

五个 triage 角色保留现有标签字符串,由所有 Agent 共用。

| triage 角色 | 本仓库 GitHub Issues 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化,可交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

处理 Issue 时使用表中对应的标签字符串,不要因切换 Codex 或 Claude Code 而改变映射。标签映射的变更由维护者决定,并同步更新本文件。
