# 领域文档

本仓库采用 single-context 布局。共享协作规则见根目录 [AGENTS.md](../../AGENTS.md)。

## 权威来源

- 探索项目时先读 [CONTEXT.md](../../CONTEXT.md):它定义项目术语与背景,不承载实现细节。
- 修改相关区域前读 [docs/adr/](../adr/) 中对应的决策;当前决策为 [ADR-0001](../adr/0001-第二阶段形态-模板仓库而非第二份指南.md) 与 [ADR-0002](../adr/0002-仓库只含流程文本.md)。
- 实践流程以 [README.md](../../README.md) 为准,方法论指回[理论指南](../../计算机视觉科研入门指南.pdf)。

## 维护约定

产出中的领域概念(包括 Issue/PR 标题、记录与报告)按 `CONTEXT.md` 的定义用词,避免使用其中明确排除的同义词。确有术语空缺时先说明,待定义落定后更新词汇表。

需要改变既有 ADR 时,明确指出具体决策、冲突内容与理由,先交由维护者决定,不得静默覆盖。仅在重要决策落定时新增或更新 ADR;不要求某个 Agent 专属技能,也不预建本项目未采用的多 context 结构。
