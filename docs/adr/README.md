# Architecture Decision Records

记录会约束后续实现的耐久决定。只有决定及其取舍已经确认后,才创建 ADR。

文件名使用顺序编号:`NNNN-kebab-case-title.md`。

每份新 ADR 包含:

- Title
- Status: `proposed`、`accepted`、`superseded` 或 `rejected`
- Context
- Decision
- Consequences
- 适用时写 Supersedes / Superseded by

[ADR-0001](0001-第二阶段形态-模板仓库而非第二份指南.md) 与 [ADR-0002](0002-仓库只含流程文本.md) 的状态是 `accepted`。它们早于上述标题模板,正文保持原样,仍然是权威决定。
